# Intrusion Detection Inference Module

This Python module enables inference with a trained Decision Tree while collecting real-time Prometheus metrics.

---

## How to Use

### Install dependencies
```bash
pip install -r requirements.txt
```

### Training
```bash
python lightweight_model_trainer.py 
```


### Live Prediction
```bash
python concurrent-requests-k8s-metrices-export-updated.py
```
